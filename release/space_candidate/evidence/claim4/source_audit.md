# Claim 4 source audit

Source: arXiv:2601.22137 HTML, retrieved 2026-07-24, SHA-256
`9876b930c97063af87fbfc8eb51e577920d2047d76abd4f71c1f63570b9a4866`.
Anchors: Section 6.2, Figure 5, Appendix E.1.

The disclosed protocol names modified stride-one ResNet-20/CIFAR-10 and
ResNet-32/CIFAR-100, Shampoo with `p=2`, learning rate `0.001`, weight decay
`0.0005`, maximum preconditioner size `2048`, and five PRISM or PolarExpress
iterations. It compares the first 50 epochs.

Missing operational fields include enlarged channel widths, batch size, data
augmentation and split, learning-rate schedule, preconditioner update/start
frequency, seeds, executable revision, raw accuracy trajectories, and the
exact wall-clock protocol.
