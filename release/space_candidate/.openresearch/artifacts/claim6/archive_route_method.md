# Exact source-archive audit

This third Claim 6 route retrieves the arXiv e-print with an explicit browser
User-Agent entirely in memory. It records the archive SHA-256 and inventories
executables, machine-readable curve data, seed statements, precision, and the
four source plots for Figure D.2.

The audit fails closed if an item needed to reconstruct the exact reported
sample is absent. Its mutation control attempts to use a PNG and a TeX prose
file as operational generator evidence; the classifier must reject that
substitution.

This route is materially different from the finite beta-Laguerre calibration
and the independent limiting-density computation: it asks whether the exact
reported experiment can be rerun from the authors' public artifact.
